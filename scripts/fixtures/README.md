# Cutout smoke fixture

`cutout-portrait.jpg` is a 384 × 480 resize of this Unsplash photo:
https://images.unsplash.com/photo-1534528741775-53994a69daeb

It is used only by the real Electron cutout smoke check and is not included in the application package.
The check verifies transparent background pixels, retained foreground pixels, unchanged dimensions, model availability without network, and project persistence.
