# 智能抠图

桌面客户端中，打开图片或参考图的“图片工具”菜单，选择“智能抠图”。结果作为新的图片节点放在原图右侧，原图保持不变。透明 PNG 保留原图尺寸与主体位置，可以下载、复制或继续作为参考图使用。

结果显示棋盘格背景，放大查看时可切换棋盘格、浅色、深色底色；这些底色仅用于预览，不会写入 PNG。抠图支持取消，切换项目或删除正在处理的结果会终止该任务。图片像素上限为 3200 万。

## 模型管理

“应用设置 → 智能抠图”提供以下模型：

| 模型 | 体积 | 获取方式 |
| --- | ---: | --- |
| IS-Net INT8 | 46.7 MB | 随安装包内置，默认启用 |
| IS-Net FP32 | 178.6 MB | 用户选择下载，原始精度版本 |
| BiRefNet Lite FP32 | 224.0 MB | 用户选择下载，另一种主体分割模型 |

下载完成后点击“使用此模型”，立即应用于下一次抠图。下载、取消下载、切换、删除均在此页面完成；删除正在使用的可选模型会恢复内置默认模型。模型保存在 Electron 用户数据目录的 `cutout-models` 文件夹，安装包升级不会清除这些下载。图片在本机处理，不需要 API Key，不会发送到云端。

内置 INT8 是从 rembg 的 IS-Net FP32 导出自行转换的**权重量化版**：卷积权重采用逐通道 INT8 存储，激活和运算保持 FP32。它降低安装包体积，不代表全 INT8 运算或更低的运行内存。权重来源、校验和和复现脚本见 [assets/models/README.md](../assets/models/README.md)。

当前后台使用 ONNX Runtime CPU 推理，一次处理一张图片，结束后释放独立进程及模型内存。网页版显示桌面版功能提示；没有自动上传图片的后备路径。

## 开发与验证

- `npm run check` 覆盖类型、Lint、回归测试和构建。模型文件需完整存在于 `assets/models/isnet-int8.onnx`，随代码检出，不依赖构建时联网下载。
- `npm run smoke:electron` 使用真实人像验证内置模型、断网推理、前景/背景 alpha、保留原图和项目重载。
- 设置环境变量 `BANANA_CUTOUT_OPTIONAL_SMOKE=1` 后运行 smoke，会额外联网下载 BiRefNet Lite，验证选择、真实推理、删除和默认模型回退。常规 CI 不执行这项网络下载检查。
- Electron Builder 将默认模型复制到 `resources/cutout/isnet-int8.onnx`，并保留 ONNX Runtime 的平台原生组件。打包后的应用必须再次执行 smoke，验证安装包内容确实能独立运行。

可选模型的固定版本 URL、字节大小与 SHA256 位于 `src/lib/cutoutModels.ts`。下载先写入 `.part`，长度和 SHA256 均通过才安装；首次使用也会校验模型。新增模型需验证输入归一化、输出 alpha 和目标 CPU 的实际性能，不能仅凭 FP16 / INT8 文件大小推断速度。
