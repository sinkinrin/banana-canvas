# Banana Canvas 项目复审与整改记录

日期：2026-07-21  
基线版本：0.2.1

## 目标

在保留 npm/Vite 与 Electron 双运行模式的前提下，提高项目的默认安全性、取消与错误处理、桌面生命周期、数据可靠性和大画布性能，并让这些行为有自动化测试覆盖。

## 本轮不直接合并的大型架构项

图片二进制 API、缩略图生成、Blob URL 生命周期和 IndexedDB 兼容迁移互相耦合，属于需要独立版本迁移策略的存储协议改造。本轮先消除重复哈希、超大签名和无关渲染，保留现有项目格式，避免用户已有项目在未经迁移验证时受损。

## 仍建议后续推进

- 将项目图片改为独立二进制读取、缩略图与 Blob URL 懒加载，彻底消除大项目加载时的全量 Base64 内存开销。
- 为 `.trash` 增加应用内恢复与自动清理界面；当前已可从磁盘人工恢复，但没有产品化入口。
- 增加连接诊断与脱敏日志导出，方便用户自行定位代理、证书和中转兼容问题。
- 扩展 Renderer smoke 为项目创建、保存、重启恢复、设置保存等完整桌面 E2E 流程。
- 正式发布前配置 Windows 代码签名；未签名安装包仍可能触发 SmartScreen。
- 如果未来允许 `HOST=0.0.0.0` 用于多人共享，需要另行增加认证、CSRF、防滥用和细粒度权限控制。
