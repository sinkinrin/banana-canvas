# 节点分类

点击创作节点或图片节点上方的“未分类”标签，选择颜色后可为该分类命名（最多 32 个字符）。同一项目内，相同颜色的节点共用名称，例如“产品 A”“场景图”“备选方向”。点击空白处、关闭按钮或按 Escape 关闭，修改自动保存。

画布左上角展开“节点分类”，可以查看各类节点数量，点击分类定位到整组节点；“未分类”和“定位全部”用于找回其它内容。定位只调整视角，不移动、隐藏或删除节点，也不会中断正在生成的任务。缩略地图使用相同分类色。

生成、对比、局部编辑、抠图和作为参考图创建的新节点继承来源分类。可单独改变结果节点的分类，或选择“未分类”清除归类。名称随所属节点保存在项目中；当该颜色已没有节点时，其名称也不再保留。旧项目已有的节点颜色会直接作为分类使用。

分类修改支持画布的撤销与重做。高级生成参数与分类分别管理，折叠高级参数不会清除或停用已选参数。
